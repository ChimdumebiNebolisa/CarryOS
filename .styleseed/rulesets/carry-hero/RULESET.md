# Carry reference grammar

This product uses a carry-on, readiness-orientation visual language for a public landing and dashboard.

- Grammar source: `reference:carry-hero`
- Domain: educational planning support
- Purpose: launch page and interactive demo that explain readiness and deterministic scan states

Core direction:

- Primary intent is operational credibility first, not AI spectacle.
- Keep one dominant visual focal point and two readable supporting sections.
- Use semantic color roles for state clarity.
- Avoid broad SaaS card grids and glass-like surfaces.
- Use deterministic interaction evidence over generic progress animations.
