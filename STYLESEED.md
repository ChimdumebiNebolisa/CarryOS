# STYLESEED

Carry uses a project-local visual lock derived from 21st.dev editorial-hero and animated-link references, compressed into a two-page public surface.

- Grammar: `reference:carry-editorial-poster`
- Adapter: website / single-viewport editorial poster + technical architecture viewer
- Display: Space Grotesk (controlled mass: clamp 2.7-4.35rem, -0.045em, 0.97 leading)
- Body: DM Sans
- Utility: DM Mono (eyebrows, departure strip, legend, node tags)
- Surfaces: split editorial poster on paper (`#F1EADF`) with a stored everyday-commute photograph (`public/images/hero-commute.jpg`); charcoal architecture board with React Flow graph and selection panel
- Status: forest green confirm, terracotta only for the model-assisted boundary, sand only for the human gate, green dotted for simulated input
- Signature: one non-scrolling homepage poster whose type column carries a mono canonical-scenario strip (`ALGORITHMS · 10:00 AM · LEAVE BY 9:35 AM`); the machinery is proven on `/how-it-works`
- Motion: one orchestrated entrance (copy rise, image settle), edge emphasis on node selection; reduced motion shows a static poster and stable Readiness selection
- Forbidden: orbiting circles, particles, WebGL, testimonials, partner logos, generic AI dashboards, multi-section marketing scroll, full-image dark scrims, glass pills, hiking/adventure imagery

Material blocker for the third field: the public site is not a multi-section landing. The homepage uses a stored commute photograph (`public/images/hero-commute.jpg`, Bayram Yalçın / Pexels) so the first screen carries the whole product.
